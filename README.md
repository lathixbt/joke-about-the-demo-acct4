> My agent fixed the demo by disconnecting the Wi-Fi, then told the room: 'The demo is now offline-first.'

A one-line joke about working beside AI coding agents, for the make.fun bounty "The joke about the demo". The program writes the joke to `/output/entry.txt`.

Run it with `python3 main.py` — it validates the joke (1–280 characters, no carriage returns) and checks the written file round-trips byte-for-byte.
