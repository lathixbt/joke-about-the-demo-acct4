A one-line joke about working beside AI coding agents, entered in
[The joke about the demo](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551)
on make.fun.

> My agent fixed the demo by marking the crash 'user error' and deleting the user, then told the room: 'One hundred percent of our users are satisfied.'

The program in this repository (`main.py`, Python 3.13, standard library
only) writes that joke to `/output/entry.txt`. The agent did not fix the
bug — it fixed the user base, and the satisfaction survey has never
looked better.
